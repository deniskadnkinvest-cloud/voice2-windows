# Voice2 — план Windows-версии и тарификации

Документ-план: как раскатать Voice2 на Windows (все ходовые конфиги), как ставить, как обновлять и как монетизировать в рублях по модели Aqua Voice / Perplexity (free 2000 слов → upgrade).

Статус: черновик плана, не код. Под подпись операторa.

---

## 1. Что делаем

| Цель | Решение |
|---|---|
| Windows-версия Voice2 | Перенос Swift → C++/Rust + Whisper.cpp (или Tauri/Electron + whisper-cli) |
| Установка | Один `.exe` (или `.msi`) — пользователь скачал, два клика, готово |
| Обновления | Авто-проверка раз в сутки, тихая фоновая установка при следующем запуске |

| Бесплатный лимит | 2000 слов в месяц free, дальше — экран «Upgrade» и блок диктовки |
| Платный план | Месячная подписка + годовая со скидкой 30% |

## 3. Архитектура Windows-версии

### Вариант A — Native C++/C# (рекомендую)
- **UI:** WPF (.NET 8) или WinUI 3 — нативный look, маленький бинарь
- **Audio:** WASAPI (loopback / capture)
- **Hotkey:** `RegisterHotKey` Win32 API
- **Whisper:** `whisper.cpp` скомпилированный под Windows MSVC + DirectML backend (опционально)
- **Вставка текста:** clipboard + `keybd_event` Ctrl+V (как Cmd+V на маке)
- **Размер:** ~250–500 MB (модель ggml-base 142 MB + .NET runtime self-contained)

### Вариант B — Tauri (Rust + WebView)
- Кросс-платформенно (Win/Mac/Linux один код)
- Меньше бинарь (~30 MB + модель)
- Но: глобальный хоткей и аудио — через rust crates, есть подводные камни на Win

### Вариант C — Electron
- Самый быстрый порт по UI
- Жирный (200 MB пустой)
- Тормозной на старых машинах — **не берём**

**Решение:** старт на варианте **A (WPF + .NET 8)**. Если будет успех — переписать ядро на Rust и упаковать Tauri, чтобы один код держал и Win, и обновлённый Mac.

## 4. Установка

### Установщик
- **Inno Setup** (классика, бесплатно, поддерживает русский)
- Один `.exe` — `Voice2-Setup-2.1.0.exe` (~250 MB вместе с моделью)
- Шаги мастера:
  1. Согласие с лицензией (русский язык)
  2. Папка установки (по-умолчанию `%LocalAppData%\Voice2`)
  3. Создать ярлык на рабочий стол + автозапуск (галочки)
  4. Запросить разрешение микрофона при первом запуске (Win API)
- **Подпись:** обязательно codesign EV-сертификатом, иначе SmartScreen ругается. ~12 000 ₽/год через российского регистратора (например, ТЕНЗОР / КриптоПро)
- **Установка без админки:** ставим в `%LocalAppData%`, не требует UAC — пользователь не упирается в политику IT-отдела

### Альтернатива — портативная версия
- ZIP с `Voice2.exe` + папка `model/` рядом
- Запуск без установки — для тех, кому корп.политика не даёт ставить софт
- Минус: нет автообновлений

## 5. Обновления

### Механика
- При запуске Voice2 ходит на `https://api.voice2.ru/version` (GET, ~200 байт)
- Сервер возвращает JSON: `{ "latest": "2.1.4", "url": "...", "min_supported": "2.0.0" }`
- Если есть обновление — скачивает `.exe` в `%LocalAppData%\Voice2\update\` в фоне
- При следующем запуске — закрывает себя, запускает downloaded `.exe`, тот ставится поверх
- Логика: **Squirrel.Windows** (open-source, юзают Slack/Discord/VS Code) или собственный мини-апдейтер на 200 строк C#

### Канал
- `stable` — релизы раз в 2 недели
- `beta` — опт-ин в настройках, обновления раз в 3–5 дней

### Сервер обновлений
- Простой: статика на S3-совместимом хранилище (Selectel / Yandex Cloud) + `version.json`
- Не нужен бэкенд для обновлений на старте

## 6. Тарификация — модель Aqua Voice / Perplexity

### Как у конкурентов

| Сервис | Free | Pro |
|---|---|---|
| **Aqua Voice** | 2000 слов/мес, потом блок | $8/мес безлимит |
| **Wispr Flow** | 14 дней trial, потом блок | $12/мес или $96/год |
| **Perplexity Pro** | 5 запросов/4ч free | $20/мес безлимит |
| **MacWhisper** | модель base бесплатно | $59 разово за large-v3 |

### Что делаем мы (Voice2)

| План | Лимит | Цена RU | Платёжка |
|---|---|---|---|
| **Free** | 2000 слов/месяц | 0 ₽ | — |
| **Pro Monthly** | безлимит | **490 ₽/мес** | ЮKassa (карты + СБП) |
| **Pro Yearly** | безлимит | **3 990 ₽/год** (скидка 32%) | ЮKassa |
| **Lifetime** (только первый год, маркетинг-ход) | безлимит навсегда | **9 990 ₽** разово | ЮKassa |

### Почему такие цены
- Wispr Flow в долларах = ~1100 ₽/мес. Мы кратно дешевле, но локально и без оттока
- 490 ₽ — психологический порог «меньше пачки сигарет». Хорошо конвертит в RU
- Lifetime — отличный буст на ранних 100–500 продаж. Закрываем оффер после набора

### Как считаем слова
- После каждой диктовки: `transcript.split_whitespace().count()` → шлём в API `POST /api/usage`
- Сервер хранит счётчик: `user_id → words_used_this_month`
- При >= 2000 — приложение блокирует кнопку «Записать» и показывает экран Upgrade
- **Локально кэшируем баланс** — если интернета нет, разрешаем дописать до +500 слов в долг

### Что НЕ блокируем у Free
- Скачивание приложения и установка — свободно
- Все настройки (язык, хоткей, тема)
- Сама модель Whisper — она уже на диске, лезть в неё не надо

## 7. Платёжная инфраструктура — рубли

### ЮKassa (наш выбор)
- Принимает: Visa/Mastercard/Мир, СБП, ЮMoney, СберPay, T-Pay, рассрочки
- Подключение: ИП или ООО (на старте — ИП, регистрация 2–3 дня)
- Комиссия: ~3.5% с операции
- Регулярные платежи (для подписки): встроено, поддерживает hold + рекуррент
- Webhook: подтверждение оплаты → активация подписки

### Архитектура биллинга (минимум)
```
[Voice2 App] → POST /api/checkout/start
                  ↓
              [Бэкенд на Python/Go]
                  ↓
            ЮKassa Payment URL
                  ↓
       [Браузер] → платежка → success_url
                  ↓
            ЮKassa webhook → /api/billing/webhook
                  ↓
       [Бэкенд] активирует подписку → user.tier = "pro"
                  ↓
       [Voice2 App] периодически дёргает /api/me → видит pro
```

### Бэкенд (минимально жизнеспособный)
- **Стек:** Python FastAPI + Postgres + Redis
- **Деплой:** Один VPS Selectel/Aeza за 500 ₽/мес
- **Endpoints:** `/api/me`, `/api/usage`, `/api/checkout`, `/api/webhook`, `/api/version`
- **Auth:** Magic-link на email (без паролей) — упрощает онбординг

### Альтернатива — Robokassa
- Если ЮKassa откажет (бывает с новыми ИП) — Robokassa менее придирчива
- Комиссия чуть выше (~4%)

### Юр.форма
- **ИП на УСН 6%** — самый простой вариант
- Открыть онлайн через Тинькофф/Сбер за 1 день
- Расчётный счёт там же бесплатно

## 11. Риски и митигации

| Риск | Вероятность | Митигация |
|---|---|---|
| ЮKassa отклонит ИП | Низкая | Заранее держать Robokassa fallback |
| Windows Defender SmartScreen блокирует .exe | Высокая | EV-сертификат с первого дня |
| Whisper тормозит на старых CPU | Средняя | Дать выбор модели: tiny (75 MB, быстро) / base (142 MB) / small (465 MB) |
| Пиратство — крякнут лимит | Высокая | Не блокируем UI на клиенте, проверяем токен на сервере. Крякнут — пускай. Платят те, кому удобно |
| MAC-юзеры обидятся что нет фич | Низкая | Параллельно держать macOS в темпе, не забрасывать |
| Конкуренты выкатят русский Wispr Flow | Средняя | Скорость релиза + цена в 2 раза ниже |
